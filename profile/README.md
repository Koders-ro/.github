## About

Koders is a software development studio based in Bucharest, Romania.

We build custom software for businesses, from web applications and SaaS platforms to internal tools, automation, and integrations.

This GitHub organization is a collection of things we build and use along the way.

## Open source

Not everything we build needs to stay private.

Some of the repositories here contain tools, utilities, and applications that started as part of our everyday work at Koders. We've decided to make them public so others can use them, learn from them, adapt them, or contribute back.

You'll find practical code rather than demo projects made just to look good in a portfolio.

Feel free to explore, fork, open issues, or send pull requests.



## Docker-friendly

We use Docker extensively in our development and deployment workflows.

Where it makes sense, we provide Dockerfiles and Docker Compose configurations, so getting an application up and running doesn't have to be a complicated process.

Check the individual repository documentation for setup instructions and requirements.

## More to come

We'll keep adding repositories as we find things worth sharing.

Some will be small utilities, others complete applications. Either way, if we think something could be useful outside our own projects, we'll try to make it available here.
